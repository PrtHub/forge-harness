## 🏗️ Technical Architecture & Stack

Forge is built using a state-of-the-art Next.js stack focused on luxury visuals, lightning-fast rendering speeds, and ironclad local privacy:

*   **Framework**: [Next.js 15](https://nextjs.org) (App Router architecture with full static-site generation support).
*   **Styling**: [Tailwind CSS v4](https://tailwindcss.com) utilizing the modern `@theme` unified utility directive.
*   **Typography**: Loaded natively via `@next/font` to eliminate layout shift:
    *   `font-cinzel` (Cinzel) for branding elements.
    *   `font-spectral` (Spectral) for high-end editorial narratives.
*   **Graphics**: 100% resolution-independent, interactive inline SVG structures (incorporating breathing CSS animations, custom glow filters, and animated particle coordinates). No heavy raster templates are downloaded.
*   **Privacy Model**: Local-only database. No accounts, no clouds, zero server exposure.

## ⚙️ Quick Start

This project is configured with `pnpm` for high-performance dependency isolation.

### 1. Installation
Install project dependencies:
```bash
pnpm install
```

### 2. Run local development server
Launch the local compiler with hot-reloading:
```bash
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) to review the live interactive application.

### 3. Production Build
Compile and optimize static pages for server deployment:
```bash
pnpm build
```
